Политика конфиденциальности Adderli

Дата последнего обновления: 8 сентября 2026 года.

Настоящая Политика конфиденциальности описывает, какие данные обрабатывает Discord-бот Adderli, для каких целей они используются и как пользователи могут запросить их удаление.

1. О приложении

Adderli — Discord-бот для автоматизации управления Discord-серверами семей и организаций, связанных с Majestic RP.

Бот предоставляет систему заявок на вступление в семью, мониторинг входа и выхода участников, автоматизацию управления участниками и функции модерации.

2. Какие данные обрабатываются

В зависимости от используемых функций Adderli может обрабатывать следующие данные:

  • Discord ID пользователя;
  • имя пользователя и отображаемое имя;
  • Discord ID сервера;
  • Discord ID и информацию о ролях пользователя;
  • данные о вступлении пользователя на сервер и выходе с сервера;
  • данные и текст заявок на вступление в семью;
  • настройки Discord-сервера, необходимые для работы бота;
  • данные, необходимые для выполнения функций и команд бота.

3. Для чего используются данные

Полученные данные используются только для обеспечения работы функциональности Adderli.

В частности, данные могут использоваться для:

  • обработки заявок на вступление в семью;
  • идентификации участников Discord-сервера;
  • отслеживания входа и выхода участников;
  • работы системы ролей и настроек сервера;
  • автоматизации управления сервером;
  • выполнения команд и функций модерации;
  • обеспечения стабильной работы бота.

4. Хранение данных

Данные могут храниться в базе данных Adderli в течение периода, необходимого для работы соответствующих функций бота.

Срок хранения зависит от типа данных и их необходимости для функционирования сервиса.

5. Передача данных третьим лицам

Персональные данные пользователей не продаются и не используются для рекламных целей.

Данные могут обрабатываться техническими поставщиками, необходимыми для работы Adderli, например поставщиком хостинга или базы данных.

6. Безопасность

Принимаются разумные технические и организационные меры для защиты хранимых данных от несанкционированного доступа, изменения или удаления.

7. Удаление данных

Пользователь или администратор Discord-сервера может обратиться с запросом на удаление данных, связанных с использованием Adderli.

Для запроса на удаление данных необходимо связаться с разработчиком по контактам, указанным ниже.

8. Изменение политики

Настоящая Политика конфиденциальности может периодически обновляться. Актуальная версия всегда публикуется на этой странице.
