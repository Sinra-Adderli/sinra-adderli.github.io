Политика конфиденциальности Adderli

Дата последнего обновления: 8 сентября 2026 года.

1. Общие положения

Настоящая Политика конфиденциальности описывает порядок обработки данных пользователей Discord при использовании Discord-бота Adderli.

Adderli является сторонним Discord-приложением и не является официальным продуктом Discord или Majestic RP.

Используя функции Adderli, устанавливая бота на Discord-сервер или взаимодействуя с его функциями, пользователь может передавать данные, необходимые для работы соответствующих функций.

2. Ответственное лицо

Разработчик Adderli: Sinra Adderli.

По вопросам обработки, доступа, исправления или удаления данных пользователь может обратиться по контактам, указанным в разделе «Контакты».

3. Источники данных

Данные могут поступать из следующих источников:

  • Discord API;
  • действия пользователя на Discord-сервере;
  • взаимодействие пользователя с функциями Adderli;
  • данные, добровольно предоставленные пользователем в системе заявок;
  • настройки, установленные администраторами Discord-сервера.

4. Какие данные обрабатывает Adderli

В зависимости от используемых функций конкретного Discord-сервера Adderli может обрабатывать следующие категории данных:

  • Discord User ID;
  • Discord Server/Guild ID;
  • имя пользователя;
  • отображаемое имя пользователя;
  • информация о ролях пользователя;
  • информация о членстве пользователя на сервере;
  • сведения о входе пользователя на сервер;
  • сведения о выходе пользователя с сервера;
  • дата и время соответствующих событий, если они сохраняются;
  • данные заявок на вступление в семью;
  • текст заявок, добровольно отправленный пользователем;
  • статус и результаты обработки заявок;
  • настройки Discord-сервера, необходимые для работы Adderli;
  • идентификаторы каналов, ролей и других объектов Discord, если они используются настройками бота;
  • технические данные, необходимые для выполнения функций и обеспечения работоспособности сервиса.

5. Данные сообщений и содержимое Discord

В зависимости от включённых функций и разрешений Discord Adderli может получать доступ к данным Discord, необходимым для выполнения соответствующих функций.

Наличие технической возможности получить определённый тип данных не означает, что Adderli постоянно сохраняет такие данные. Сохраняются только данные, которые необходимы для работы реализованных функций и которые фактически используются приложением.

Adderli не предназначен для постоянного архивирования всех сообщений пользователей Discord.

6. Цели обработки данных

Данные используются исключительно для работы и обеспечения функций Adderli.

В частности, данные могут использоваться для:

  • обработки заявок на вступление в семью;
  • отображения и обработки информации о заявителях;
  • идентификации участников Discord-сервера;
  • мониторинга входа и выхода участников;
  • ведения журналов событий;
  • работы с ролями пользователей;
  • сохранения настроек Discord-сервера;
  • автоматизации действий на Discord-сервере;
  • выполнения команд и взаимодействий с ботом;
  • обеспечения безопасности и стабильности сервиса;
  • предотвращения злоупотреблений и неправомерного использования.

7. Правовые основания обработки

В зависимости от обстоятельств обработка данных может осуществляться на основании согласия пользователя, необходимости выполнения действий по его запросу, законного интереса разработчика или администратора сервера, а также иных оснований, предусмотренных применимым законодательством.

Конкретное правовое основание может зависеть от типа данных, функции Adderli и юрисдикции пользователя.

8. Минимизация данных

Adderli стремится обрабатывать только те данные, которые необходимы для предоставления соответствующей функции.

Данные не используются для целей, несовместимых с целями, описанными в настоящей Политике конфиденциальности, за исключением случаев, предусмотренных применимым законодательством.

9. Хранение данных

Данные могут храниться в базе данных Adderli в течение периода, необходимого для выполнения соответствующей функции.

Срок хранения зависит от типа данных, назначения данных, настроек Discord-сервера и необходимости их дальнейшего использования.

Когда данные больше не требуются для соответствующей цели, они должны быть удалены или обезличены, если их дальнейшее хранение не требуется по закону или для защиты законных прав и интересов.

10. Удаление данных при удалении бота

Удаление Adderli с Discord-сервера прекращает дальнейшее использование ботом данных этого сервера.

Данные, связанные с сервером, могут сохраняться в течение периода, необходимого для выполнения процедур удаления, резервного копирования, безопасности или иных законных целей.

По запросу администратора сервера данные могут быть удалены в соответствии с настоящей Политикой и применимым законодательством.

11. Передача данных третьим лицам

Adderli не продаёт персональные данные пользователей и не передаёт их третьим лицам для самостоятельного использования в рекламных целях.

Для работы сервиса данные могут обрабатываться поставщиками технической инфраструктуры, включая хостинг, базы данных, серверную инфраструктуру и другие необходимые сервисы.

Такие поставщики могут получать только тот объём данных, который необходим для предоставления соответствующей услуги.

12. Международная передача данных

В зависимости от расположения используемой инфраструктуры данные могут обрабатываться или храниться на территории разных государств.

В случаях, когда законодательство требует применения дополнительных механизмов защиты при передаче данных, разработчик стремится применять соответствующие меры, предусмотренные применимым законодательством.

13. Безопасность

Для защиты данных применяются разумные технические и организационные меры безопасности.

Такие меры могут включать ограничение доступа к базе данных, контроль доступа к серверной инфраструктуре, использование защищённых соединений и другие стандартные меры защиты.

При этом ни один способ хранения или передачи данных через Интернет не может гарантировать абсолютную безопасность.

14. Доступ к данным

Доступ к сохранённым данным предоставляется только лицам и техническим системам, которым такой доступ необходим для работы, поддержки или обеспечения безопасности Adderli.

15. Права пользователей

В зависимости от применимого законодательства пользователь может иметь право:

  • получить информацию об обработке своих данных;
  • получить копию своих данных;
  • исправить неточные данные;
  • потребовать удаления данных;
  • ограничить обработку данных;
  • возразить против определённых видов обработки;
  • получить данные в переносимом формате;
  • отозвать ранее предоставленное согласие, если обработка основана на согласии.

Эти права могут иметь исключения и ограничения, предусмотренные применимым законодательством.

16. Запрос на удаление данных

Для запроса на удаление данных пользователь может обратиться к разработчику по контактам, указанным ниже.

В запросе рекомендуется указать Discord User ID и описание данных, которые необходимо удалить.

Для защиты от удаления данных по запросу постороннего лица разработчик может запросить разумное подтверждение того, что запрос действительно относится к соответствующему пользователю.

Запросы обрабатываются в сроки, предусмотренные применимым законодательством.

17. Ограничения удаления

В отдельных случаях данные могут временно сохраняться, если их хранение необходимо для выполнения юридической обязанности, обеспечения безопасности, предотвращения злоупотреблений, разрешения споров или защиты законных прав и интересов.

Резервные копии могут сохраняться в течение ограниченного технического периода, необходимого для их безопасного удаления или перезаписи.

18. Автоматизированная обработка

Некоторые функции Adderli могут выполняться автоматически на основании настроек Discord-сервера и данных, полученных через Discord API.

Если автоматизированная обработка используется для принятия решений, которые имеют юридические или иным образом существенно значимые последствия для пользователя, соответствующая информация предоставляется дополнительно в соответствии с применимым законодательством.

19. Несовершеннолетние

Adderli не предназначен для самостоятельного сбора дополнительных персональных данных детей.

При обработке данных несовершеннолетних применяются требования применимого законодательства и правила Discord.

20. Информация о Discord

Adderli является сторонним приложением Discord. Discord самостоятельно обрабатывает данные пользователей в соответствии со своей политикой конфиденциальности.

Adderli не контролирует обработку данных, которую осуществляет Discord вне функций стороннего приложения.

21. Изменение Политики конфиденциальности

Настоящая Политика конфиденциальности может периодически обновляться в связи с изменением функциональности Adderli, законодательства или используемой инфраструктуры.

Актуальная версия политики всегда публикуется на этой странице.
